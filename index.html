LeadGen.js

A lightweight, zero-dependency JavaScript library that captures leads directly to Google Sheets. No backend required.

📦 Installation

<script src="https://cdn.jsdelivr.net/gh/NileGazer00/leadgen.js/leadgen.js"></script>
<div id="leadgen-form"></div>

⚙️ Basic Usage

LeadGen.init({
  sheetId: "YOUR_GOOGLE_SHEETS_ID",
  theme: "dark"
});

📊 Calculate Leads Needed

// How many leads to hit $21k/month?
LeadGen.calculateNeeded(21000, 499);
// Returns: 42 leads

📤 Google Sheets Setup

  1. Create a Google Sheet
  2. Copy the Sheet ID from the URL
  3. Enable Google Sheets API in Google Cloud Console
  4. Create an API key and restrict it to Sheets API

📝 API Reference

LeadGen.init(config)           // Initialize the form
LeadGen.calculateNeeded(target, avg)  // Calculate leads needed
LeadGen.setTheme(theme)        // Change theme (dark/light)
LeadGen.getAnalytics()         // Get submission stats

🧪 Try It Now

Open your browser console (F12) and run:

calculateLeadsNeeded(21000, 499); // Returns 42 leads needed per month
