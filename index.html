📜 Installation

<script src="https://cdn.jsdelivr.net/gh/NileGazer00/leadgen.js/leadgen.js"></script>
<div id="leadgen-form"></div>

Copy these two lines into any HTML file. That's it.

⚙️ Usage

// Initialize the form
LeadGen.init({
  sheetId: "YOUR_GOOGLE_SHEETS_ID",
  theme: "dark"
});

// Calculate leads needed
LeadGen.calculateLeadsNeeded(21000, 499); // 42 leads
