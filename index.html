LeadGen.js

40 lines of vanilla JS that capture leads → Google Sheets. No backend. No cost.

📖 Documentation ⭐ GitHub

📜 Installation

<script src="https://cdn.jsdelivr.net/gh/NileGazer00/leadgen.js/leadgen.js"></script>
<div id="leadgen-form"></div>

⚙️ Usage

// Initialize the form
LeadGen.init({
  sheetId: "YOUR_GOOGLE_SHEETS_ID",
  theme: "dark"
});

// Calculate leads needed for revenue goal
LeadGen.calculateLeadsNeeded(21000, 499); // 42 leads

📤 Google Sheets Setup

  1. Create a Google Sheet
  2. Get your Sheet ID from the URL
  3. Enable Google Sheets API
  4. Create an API key
